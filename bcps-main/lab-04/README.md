# Lab 04 — Professional document in Writer

**Aim:** Format a professional document with text formatting, a table, headers, footers, and page numbers.

Open `workshop-plan.odt` in LibreOffice Writer. It is an editable, fictional workshop plan containing all five features.

## Procedure

1. Create a text document and save it as an ODT file.
2. Enter the workshop title and apply the Title paragraph style. Apply Heading 1 to section headings and Text Body to paragraphs.
3. Format the submission note with bold and italic text.
4. Use **Table > Insert Table** to create the five-row, three-column programme table. Enter the headings and four activities.
5. Enable the header and footer using **Insert > Header and Footer**. Add the course label in the header.
6. In the footer, type `BCPS lab record | Page ` and use **Insert > Field > Page Number**. This is an automatic field, not a typed number.
7. Use Print Preview to check margins and spacing, then save.

**Result:** A one-page document with structured headings, bold/italic text, a bordered table, a running header, and automatic footer page numbering.

**Checked:** Reopened with LibreOffice, exported to a temporary PDF, and visually reviewed the complete page.

Reference: [LibreOffice Writer Help](https://help.libreoffice.org/latest/en-US/text/swriter/main0000.html).
